# MotoNav iOS 0.16.2 Build 22：1.75C 双启动版适配

基于本仓库 Build 21（保留原导航、规划、偏航、到达、语音与蓝牙修复）。圆屏参考 [Charlie-healer/ESP32S3 fe5241e](https://github.com/Charlie-healer/ESP32S3/tree/fe5241efd5fc0bf0b2e03ac3f4bb2dd99fbcddb6) 的 1.75C 固件 v7.12.11-175c.1；Mobee 的双启动补丁没有改变这些蓝牙协议。此分支不改固件、分区或设备绑定。

| 功能 | 对照与处理 |
| --- | --- |
| 开始导航、地图、时钟、天气、歌词、媒体按键 | 沿用现有 iOS 实现；不替换导航引擎。 |
| Apple Music / 本地系统音乐封面与进度 | 从已授权的系统播放器读取 artwork 与播放进度，适配 type 6 封面和 #Z 扩展。 |
| QQ 音乐、网易云等的封面 | iOS 蓝牙媒体协议不提供图片。可另行启用 Apple iTunes 查询，按歌名、歌手及可用专辑名精确匹配。不采用参考实现里的 QQ、网易云未公开接口；未匹配时不显示错误图。 |
| iPhone 电量及充电状态 | 已验证的蓝牙连接上按变化发送 #PB。未启用不读取，也不上传电量。 |
| AOD、抬腕、首页样式和 MIN/RICH | 固件本机设置；不拟造未实现的手机控制接口。 |
| OBD、胎压、手机通知、目的地抽屉与其他扩展 | 固件提供接收或显示代码，但对应 Charlie 快照的 iOS 工程没有相应发送实现。未新增传感器协议、跨 App 通知读取或目的地下发。 |

设置路径：**圆屏 → 圆屏设置 → 1.75C 圆屏扩展**，只对当前已验证连接的圆屏打开。扩展和独立的联网查封面开关均默认关闭，每台圆屏分别保存。两个音乐模式沿用原「音乐控制」开关：关闭时可授权 Apple Music；开启时使用蓝牙媒体按键，可选联网匹配。查询只发送歌名与歌手到 Apple iTunes；不会上传专辑名、设备 ID、电量或定位。专辑名只参与本地匹配。

导航或巡航期间暂缓发送封面；路线和底图可打断封面传输。固件未实现参考 iOS 使用的 #ZCOV 清除指令，因此如果之前显示过封面，改用空白封面消除旧歌曲图片。是否收到封面以圆屏回执为准。

## 实机验收

1. 签名安装新的 IPA，不卸载旧版。用原签名身份和相同 Bundle ID，避免丢失配置。
2. 连接 MotoNav，不启动导航；打开扩展，检查圆屏的手机电量。用 Apple Music 模式试本机封面和进度。
3. 如需测试系统媒体模式，先完成 iPhone 系统蓝牙配对；播放歌曲，确认切歌正常，再选择是否开启联网封面。让两首歌快速切换，核对旧封面不会覆盖新歌曲。
4. 用先前验证过的模拟路线测试基础导航，观察发图期间媒体不抢占；退出后再验证圆屏与 Mobee 双向切换。
