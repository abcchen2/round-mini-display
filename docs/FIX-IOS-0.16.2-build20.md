# iOS 0.16.2 Build20：距离、路口状态与到达

继续使用高德摩托车网页算路、自行车高德 iOS 搜索接口和现有圆屏协议；没有增加地图服务、导航 SDK 或第三方算路依赖。
手机原始定位在边界处从 WGS-84 转为 GCJ-02；高德路线点、搜索坐标及地图绘制仍使用 GCJ-02，不重复转换。

## 实时距离与文案

原实现将按位置计算的剩余距离与高德整段 instruction 拼接；后者仍包含原始“行驶 N 米后转弯”，
导致播报和文字混入整段固定距离。现在按当前沿程进度到转向点的实际路线几何计算剩余距离，
转向文案由结构化 action 生成，界面保留路名，语音不再照读固定路段长度。
保留每档每事件一次的去重，补充 30 米路口提示；支持“掉头”和“调头”的动作编码。

## 路口切段

原实现距分段结束前约 2 米即可切到下一动作；路口 GPS 漂移可能提前显示下一右转。
现在明确比较当前入路延长线与转后路段：实际位于出路、连续定位跨过确认时间、航向及几何一致时才切换。
浅角左岔路旁继续直行不能仅凭航向差小而被当成已左转。模拟导航按几何进度确定切段。

## 终点候选与完成

将接近终点、候选确认及已完成分开。候选要求最后路段、物理终点距离、定位质量及无歧义匹配证据；
连续多笔定位跨时间确认后锁定完成。候选期间允许进入园区的小幅横向偏离，
同时抑制普通偏航重算、旧转向播报和迟到的换线结果。明确沿原路远离终点则退出候选。
不再叠加旧“剩余必须小于 15 米”等第二层独立完成门槛，也不要求必须先在远处激活到达检测。
环线起点、重叠回程、高架交叉及定位跳变仍有防提前完成保护。

## 路线来源、起点与候选方案

- 修复旧“我的位置”恢复成固定历史坐标：显式保存动态当前位置语义，兼容旧历史记录，恢复动态起点时要求按当前定位重新规划。
- 可靠航向必须同时满足移动速度、水平定位精度和已知 courseAccuracy。仅在高德第一方案明显反向、另一个明确同向且代价相近时调整方案优先级。
- 重算只在高德实际返回的方案中选择；查询起点和航向来自同一时刻，不反转、拼造或强制把右转路线改成左转。
- 拒绝跨分段缺少连接的折线，避免把缺失道路直接画成连接线；单个坏方案不再导致其他有效方案一起丢失。
- 界面显示已重新规划的次数，重算语音明确提示开始与完成；可选诊断日志仅新增路线标识和方案序号，不记录坐标、Key 或 Cookie。

蓝线本身朝右不必然是显示算法错误，也可能来自高德方案、道路吸附或通行规则；本版修正已确认的 App 侧旧起点和选项问题，
不能代替对具体问题路口的原始路线核验。高德网页接口的可用性和上游数据仍需真机验证。
